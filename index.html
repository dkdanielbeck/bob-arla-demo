Type One — Chat Assistants

Chat AI

You bring a question, document, or task. They bring broad, general knowledge and the ability to reason, write, summarise, and research. Best used conversationally — you steer, they produce.

The right tool depends on your ecosystem. Gemini slots naturally into Google Workspace; Copilot into Microsoft 365. ChatGPT and Claude are standalone assistants with no ecosystem dependency — pick whichever fits your workflow.

Use Chat AI for writing, research, brainstorming, summarising documents, drafting emails, and explaining complex topics. These tools are not connected to your codebase or internal systems unless explicitly configured.

Type Two — Coding Agents

AI for Software Development

These tools go far beyond code suggestions. They read your entire codebase, write and edit files, run tests, fix failures, and open pull requests — autonomously. You describe a task; they do the work.

They live in your terminal or IDE, not in a chat window. The interaction model is closer to delegating a task to a junior developer than to having a conversation.

These are tools for software engineers. If you are not writing code yourself, the relevant question is: does your dev team have access to the right one?

Hands-On — Build & Ship

Deploy with Bob & GitHub Pages

From prompt to live website in under five minutes — no server, no build pipeline, no cost.

  1. 1 Have IBM Bob generate the app using HTML, CSS, and JavaScript.
  2. 2 Ensure the main file saved to your computer is named index.html.
  3. 3 Create a new public repository on GitHub.
  4. 4 Click uploading an existing file on the quick setup page and drag-and-drop your index.html file into the browser.
  5. 5 Click Commit changes to upload the file.
  6. 6 Go to the repository Settings, then click Pages in the left sidebar.
  7. 7 Under "Build and deployment," verify the branch is set to main.  PNG
  8. 8 Wait a minute, refresh the page, and click your new live website link. 🎉
